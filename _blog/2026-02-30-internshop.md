Congrats! You are now part of the CGR Lab. This sections outlines the skills we recommend you develop before/during starting a project in our lab.

The first step is to learn Bash scripting. You can use either of the following resources:[Data Carpentry](https://datacarpentry.github.io/shell-genomics/05-writing-scripts.html) or [MIT missing course](https://missing.csail.mit.edu/). 


If you come from a non-engineering or non-computer science background, you should also make sure you have solid, hands-on experience with Python. There are many free online Python courses available on platforms such as DataCamp, Coursera, and Codecademy, as well as plenty of tutorials on YouTube. You can also check out Reddit’s [r/learnpython](https://www.reddit.com/r/learnpython/comments/10rlgnu/recommended_free_online_python_courses/) community for recommendations and learning resources. The essential topics to cover include: Variables and basic data types, for loops, if condition, Reading/writing text files, Dictionaries, Functions, Installing/importing Python packages/libraries with pip/conda. It would also be useful to learn the basics of the Biopython package, particularly how to use it to read and work with FASTQ and FASTA files.
